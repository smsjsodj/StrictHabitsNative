# Strict Habits Desktop для Windows

Desktop приложение для Windows с синхронизацией с Android приложением через общий файл.

## Установка

1. Запустите `install.bat` - установит Python и все зависимости
2. После установки запускайте `run.bat` для запуска приложения

## Как работает синхронизация

Приложение создает файл `sync_data.json` в папке `Documents/StrictHabits/`.

### Синхронизация с телефоном:

**Вариант 1: Google Drive / Dropbox**
1. Установите Google Drive или Dropbox на ПК и телефон
2. В desktop приложении нажмите "Изменить папку синхронизации"
3. Выберите папку внутри Google Drive/Dropbox (например: `C:\Users\YourName\Google Drive\StrictHabits\`)
4. На телефоне в Android приложении настройте путь к этой же папке
5. Данные будут автоматически синхронизироваться через облако

**Вариант 2: Общая папка в локальной сети**
1. Создайте общую папку на ПК
2. Подключите её на телефоне через ES File Explorer или подобное
3. Укажите эту папку в обоих приложениях

**Вариант 3: Ручная синхронизация через USB**
1. Скопируйте `sync_data.json` с ПК на телефон вручную через USB
2. Поместите в папку где его ждет Android приложение

## Требования

- Windows 7/8/10/11
- Python 3.8+ (устанавливается автоматически через install.bat)

## Функции

- ✅ Управление привычками
- ✅ Управление блокировками  
- ✅ Автоматическая синхронизация каждые 5 секунд
- ✅ Кнопка ручной синхронизации
- ✅ Выбор папки для синхронизации
- ✅ Поддержка Google Drive / Dropbox / локальная сеть

## Интеграция с Android

В Android приложении нужно добавить:
1. Чтение/запись `sync_data.json` из выбранной папки
2. Автоматическая синхронизация при изменении данных
3. Настройка пути к файлу синхронизации в Settings

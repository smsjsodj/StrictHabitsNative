# 📱💻 Настройка синхронизации между Android и ПК

## Что изменилось

### ✅ Синхронизация через файл
- Теперь используется **файловая синхронизация** вместо Firebase
- Файл синхронизации: `Documents/StrictHabits/sync_data.json`
- Автоматическое создание папки при первом запуске

### ✅ Режим таймера в блокировках
- Добавлена галочка **"⏱️ Режим таймера"** при создании блокировки
- При включении таймера показывается **обратный отсчет времени** до конца блокировки
- Работает как на Android, так и на ПК

### ✅ Блокировка экрана на ПК
- **Красный полноэкранный режим** с таймером
- Автоматическая активация при наступлении времени блокировки
- Поддержка режима таймера

## 🚀 Установка и запуск

### Android приложение

1. Соберите APK:
```bash
cd C:\Users\smsjs\my-app\StrictHabitsNative
./gradlew assembleDebug
```

2. Установите на телефон:
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

3. Путь к файлу синхронизации на Android:
   - `Documents/StrictHabits/sync_data.json`

### Desktop приложение (Windows)

1. Установите зависимости:
```bash
cd desktop-app
npm install
```

2. Запустите приложение:
```bash
npm start
```

3. Соберите установщик (опционально):
```bash
npm run build:win
```

## 📂 Синхронизация данных

### Автоматическая синхронизация

Файл синхронизации находится по пути:
- **Windows**: `C:\Users\<username>\Documents\StrictHabits\sync_data.json`
- **Android**: `Documents/StrictHabits/sync_data.json`

### Как синхронизировать

#### Вариант 1: Облачное хранилище (рекомендуется)
1. Настройте синхронизацию папки `Documents/StrictHabits` с:
   - Google Drive
   - OneDrive
   - Dropbox
2. Данные будут синхронизироваться автоматически

#### Вариант 2: Вручную
1. На Android нажмите **"Синхронизация"**
2. Скопируйте файл `Documents/StrictHabits/sync_data.json` на ПК
3. В desktop-app нажмите **"🔄 Синхронизировать"**

#### Вариант 3: USB подключение
1. Подключите телефон к ПК через USB
2. Скопируйте файл из `Documents/StrictHabits/sync_data.json` телефона в ту же папку на ПК
3. Перезапустите desktop-app

## ⏱️ Использование режима таймера

### На Android

1. Откройте **"Управление блокировками"**
2. Добавьте или отредактируйте блокировку
3. Поставьте галочку **"⏱️ Режим таймера"**
4. Во время блокировки будет показываться обратный отсчет времени

### На ПК

1. Откройте вкладку **"Блокировки"**
2. Нажмите **"+ Добавить блокировку"**
3. Поставьте галочку **"⏱️ Режим таймера"**
4. При наступлении времени блокировки появится красный экран с таймером

## 🔴 Блокировка экрана на ПК

### Как это работает

1. Desktop-app проверяет активные блокировки каждую минуту
2. При наступлении времени блокировки:
   - Экран становится **красным**
   - Показывается **название блокировки**
   - Если включен режим таймера - показывается **обратный отсчет**
3. Блокировка автоматически снимается по окончании времени

### Настройка блокировок

- Время начала и конца
- Дни недели
- Режим таймера (опционально)

## 🛠️ Устранение проблем

### Синхронизация не работает

1. Проверьте, что файл существует в `Documents/StrictHabits/sync_data.json`
2. Убедитесь, что папка доступна для записи
3. Проверьте права доступа к файлам

### Desktop-app не показывает блокировку

1. Проверьте, что блокировка **включена** (enabled: true)
2. Убедитесь, что выбран правильный **день недели**
3. Проверьте **время** начала и конца блокировки
4. Нажмите **"🔄 Синхронизировать"** для обновления данных

### Android не синхронизирует данные

1. Проверьте разрешения на запись в хранилище
2. Убедитесь, что папка `Documents/StrictHabits` создана
3. Нажмите кнопку **"Синхронизация"** в приложении
